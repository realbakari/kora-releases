# Kora releases

Signed and notarised downloads of **Kora**, a Mac app for keeping a community organisation's archive — photographs, recordings, flyers and documents — in one place on your own Mac.

- **Download:** the latest version is on the [Releases](https://github.com/realbakari/kora-releases/releases/latest) page.
- **Updates:** Kora checks `appcast.xml` in this repository for new versions. On its second launch it asks whether to check automatically; **Kora › Check for Updates…** always works. Every update is signed, and Kora installs only updates signed with Kora's key.

This repository holds only release downloads and the update feed.
